## Introduction

This document outlines the Accessibility Conformance Testing (ACT) procedures for ensuring web components' compliance with the Web Content Accessibility Guidelines (WCAG) 2.2, focusing on the provision and implementation of alternative text (alt text) for images and graphical elements. Alt text plays a crucial role in making visual content accessible to users who rely on screen readers or have conditions that prevent them from seeing images. By providing a text-based description, alt text ensures that all users have equal access to the information conveyed by images, enhancing the overall accessibility and usability of web content.

## Accessibility Requirements

The Alternative Text is evaluated against the following WCAG 2.2 success criteria, categorized under the Perceivable, Operable, Understandable, and Robust (POUR) principles:

### Perceivable
- 1.1.1 Non-text Content: All non-text content that is presented to the user has a text alternative that serves the equivalent purpose.

### Robust
- 4.1.2 Name, Role, Value: For all user interface components (including but not limited to: form elements, links, and components generated by scripts), the name and role can be programmatically determined; states, properties, and values that can be set by the user can be programmatically set; and notification of changes to these items is available to user agents, including assistive technologies.

## ACT Test Cases

### Test Case 1: Verification of Alt Text for Non-Decorative Images

#### Objective

To ensure that non-decorative images are accessible by verifying their alternative text using a screen reader, ensuring it accurately describes the image's content and purpose.

#### Test Steps
1. Use a screen reader to navigate through the web page and identify all non-decorative images.
2. Confirm that the screen reader correctly identifies each element as an "image."
3. Listen to the alternative text read out by the screen reader for each image.
4. Assess whether the alternative text accurately describes the purpose, meaning, or context intended by the image.

#### Expected Results
- The screen reader must identify each non-decorative image correctly.
- The alternative text read by the screen reader must accurately describe the image's purpose, meaning, or context.

### Test Case 2: Evaluation of Decorative Images with Screen Readers

#### Objective

To verify that decorative images are appropriately marked to be ignored by screen readers, ensuring they do not interfere with the user's navigation and understanding of the page content.

#### Test Steps
1. Identify images classified as decorative on the web page.
2. Navigate the page using a screen reader to determine if it attempts to read any alternative text for these images.
3. Confirm that the screen reader completely ignores these decorative images.

#### Expected Results
- Decorative images must not be announced by the screen reader.
- The screen reader should skip over decorative images without attempting to read any alternative text.

### Test Case 3: Accessibility of Alternative Text When Images Are Disabled

#### Objective

To ensure that alternative text for images is still accessible and readable when images are disabled or in high contrast modes, facilitating access for users with visual impairments.

#### Test Steps
1. Disable images in the browser settings or switch the operating system to a high contrast mode.
2. Navigate the web page to check for the visibility and readability of alternative text in place of images.
3. Assess whether the alternative text is presented with sufficient contrast, and is not clipped or overlapped by other page elements.

#### Expected Results
- In the absence of images, alternative text must be visible and readable.
- The alternative text should have sufficient contrast against its background.
- The text must not be clipped or overlapped, ensuring it is fully accessible to users relying on visual adjustments.

These test cases provide a comprehensive framework for evaluating the accessibility of alternative text in web components, ensuring compliance with WCAG 2.2 guidelines and enhancing the usability of web content for users with disabilities.

### Test Case 4: Alternative Text for Complex Images (Charts, Graphs)

#### Objective

To ensure that complex images such as charts and graphs have detailed alternative text or a linked detailed description that accurately conveys the same information.

#### Test Steps
1. Identify all complex images, including charts and graphs.
2. Check for the presence of concise alt text providing a summary of the image's content.
3. Verify if a detailed description is provided either as part of the alt text or through a link to a separate text-based content.

#### Expected Results
- Complex images must have concise alt text and, where necessary, a link to detailed text-based information.
- The information conveyed through alt text and any linked detailed descriptions must accurately represent the data or information shown in the complex images.
