# Design practices testing matrix

Start with the guide’s intended outcome and supported variant. **A** identifies a canonical test with direct or partial WCAG 2.2 A/AA evidence. **B** identifies best practice. **A/B** indicates that a test can support standards evidence and may include a stronger design expectation. Open the [canonical references](Canonical%20References.md) for the exact test title, relationship and source scope. The QA scripts are supporting procedures, and several apply to only part of a pattern. Use the Cosmos procedure for the parts they do not cover. Refer to the [workflow and evidence rules](README.md) before scoring.
