# Canonical QA references

The table labels in the matrices summarise these relationships for selection. A relationship only supports a standards decision after the full criterion, conditions and exceptions are assessed. See [Link purpose in context](Review.md#link-purpose-and-external-navigation) for the difference between the register’s CTL-136 relationship and the library’s stronger wording.
