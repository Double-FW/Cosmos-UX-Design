# Infographics

Use a figure and caption to identify the graphic. Provide a concise summary of the main finding and an accessible description or data table for detailed comparisons. Make axes, units, categories and relationships understandable through text. Pair colour with labels, shapes or patterns.

## Implementation

For an image, describe what the graphic shows and use the caption to explain the main conclusion. For a single inline SVG image, provide an accessible name. If the chart hides data behind hover interactions, provide an equivalent way to obtain those values with the keyboard or in a table. Link the table and visualisation so users can choose either view.

## Checkpoints for the tester

1. Read the alternative without viewing the image.
2. Can you identify the main finding and compare the values needed for the task?
3. Inspect the graphic in monochrome and at increased zoom.
4. For tabular equivalents follow [Data Tables](Data%20Tables.md).
